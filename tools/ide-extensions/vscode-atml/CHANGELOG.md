# Changelog

## 0.1.2

- Fixed inheritance hovers for array-of-tables entries so values from unrelated
  entries and sibling parents are no longer combined.

## 0.1.1

- Renamed the extension to **ATML Tools** for a distinctive Marketplace identity.

## 0.1.0

- Initial Visual Studio Code release.
- Added TOML 1.1 and ATML highlighting.
- Added diagnostics, completion, hover, symbols, and navigation.
- Added Semantic Tokens, safe rename, and conservative Quick Fixes.
- Bundled native language servers for Linux, Windows, and macOS on x64 and ARM64.
